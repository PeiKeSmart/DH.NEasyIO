# 业务系统集成示例

本文档展示如何在业务系统中集成 EasyIO 文件上传/下载服务，包括完整的前后端代码示例，特别是**内部项目文件（AccessLevel=3）的安全访问方案**。

> **⚠️ 重要提示：实际项目关键差异**
> 
> ### 通用规则
> 1. **POST/DELETE 请求使用 Form 参数**（`multipart/form-data`），不是 JSON Body
> 2. **GET 请求使用 Query 参数或请求头**，不能使用表单
> 3. **必填请求头**：`X-External-UserId`（外部用户ID，用于身份验证）
> 4. **响应结构**：使用 `DGResult<T>` 包装，包含 `Code`、`ErrCode`、`Message`、`Data`
> 5. **令牌字段名**：返回的是 `uploadToken`（不是 `token`）
> 6. **API 基础路径**：`/api/v1/io/...`（注意版本号）
> 
> ### 内部项目文件（AccessLevel=3）特殊要求
> 7. **身份验证**：必须通过业务后端验证用户身份和权限
> 8. **访问方式**：推荐后端代理下载，或使用短期访问令牌（<30分钟）
> 9. **禁止直连**：前端不得直接调用 EasyIO API 获取内部文件
> 10. **审计日志**：必须记录所有内部文件的访问操作

## 核心优势

1. **前端直传**：文件不经过业务服务器，减少带宽和CPU消耗（适用于公开/私有文件）
2. **安全可控**：令牌绑定文件哈希，防止滥用；内部文件强制权限验证
3. **断点续传**：支持大文件分片上传，网络中断可恢复
4. **统一管理**：所有文件集中存储，便于审计和管理
5. **灵活访问控制**：支持 4 级访问权限（默认/公开/私有/内部项目）

```csharp
/// <summary>EasyIO 客户端实现</summary>
public class EasyIOClient : IEasyIOClient
{
    private readonly HttpClient _httpClient;
    private readonly EasyIOConfig _config;

    public EasyIOClient(HttpClient httpClient, IOptions<EasyIOConfig> config)
    {
        _httpClient = httpClient;
        _config = config.Value;
        _httpClient.BaseAddress = new Uri(_config.BaseUrl);
    }

    /// <summary>生成上传令牌</summary>
    /// <param name="externalUserId">外部用户ID（必填）</param>
    public async Task<UploadTokenResponse> GenerateUploadTokenAsync(GenerateTokenRequest request, String externalUserId)
    {
        // 构造表单数据
        var formData = new MultipartFormDataContent
        {
            { new StringContent(request.FileHash), "fileHash" },
            { new StringContent(request.FileName), "fileName" },
            { new StringContent(request.FileSize.ToString()), "fileSize" }
        };

        if (!String.IsNullOrEmpty(request.Category))
            formData.Add(new StringContent(request.Category), "category");
        if (!String.IsNullOrEmpty(request.BusinessType))
            formData.Add(new StringContent(request.BusinessType), "businessType");
        if (!String.IsNullOrEmpty(request.BusinessId))
            formData.Add(new StringContent(request.BusinessId), "businessId");
        if (request.AccessLevel > 0)
            formData.Add(new StringContent(request.AccessLevel.ToString()), "accessLevel");
        if (!String.IsNullOrEmpty(request.Directory))
            formData.Add(new StringContent(request.Directory), "directory");
        if (request.ExpiresInMinutes != 60)
            formData.Add(new StringContent(request.ExpiresInMinutes.ToString()), "expiresInMinutes");

        // 添加签名头
        var timestamp = DateTimeOffset.UtcNow.ToUnixTimeSeconds().ToString();
        var signature = CalculateSignature("POST", "/api/v1/io/upload-token", timestamp);

        var httpRequest = new HttpRequestMessage(HttpMethod.Post, "/api/v1/io/upload-token")
        {
            Content = formData
        };
        httpRequest.Headers.Add("X-Api-Key", _config.ApiKey);
        httpRequest.Headers.Add("X-Project-Code", _config.ProjectCode);
        httpRequest.Headers.Add("X-Timestamp", timestamp);
        httpRequest.Headers.Add("X-Signature", signature);
        httpRequest.Headers.Add("X-External-UserId", externalUserId); // 必填请求头

        var response = await _httpClient.SendAsync(httpRequest);
        response.EnsureSuccessStatusCode();

        var json = await response.Content.ReadAsStringAsync();
        var result = JsonSerializer.Deserialize<DGResult<UploadTokenResponse>>(json, new JsonSerializerOptions
        {
            PropertyNameCaseInsensitive = true
        });

        if (result?.Code != 200)
            throw new Exception($"生成令牌失败：{result?.Message} (ErrCode: {result?.ErrCode})");

        return result.Data;
    }

    /// <summary>查询文件信息</summary>
    public async Task<FileInfoResponse> GetFileInfoAsync(Int64 fileId)
    {
        var timestamp = DateTimeOffset.UtcNow.ToUnixTimeSeconds().ToString();
        var signature = CalculateSignature("GET", $"/api/v1/io/info/{fileId}", timestamp);

        var request = new HttpRequestMessage(HttpMethod.Get, $"/api/v1/io/info/{fileId}");
        request.Headers.Add("X-Api-Key", _config.ApiKey);
        request.Headers.Add("X-Project-Code", _config.ProjectCode);
        request.Headers.Add("X-Timestamp", timestamp);
        request.Headers.Add("X-Signature", signature);

        var response = await _httpClient.SendAsync(request);
        response.EnsureSuccessStatusCode();

        var json = await response.Content.ReadAsStringAsync();
        var result = JsonSerializer.Deserialize<ApiResult<FileInfoResponse>>(json, new JsonSerializerOptions
        {
            PropertyNameCaseInsensitive = true
        });

        return result?.Data;
    }

    /// <summary>获取内部项目文件（需身份验证，返回文件流用于代理下载）</summary>
    public async Task<Stream> GetInternalFileAsync(Int64 fileId, String externalUserId)
    {
        var timestamp = DateTimeOffset.UtcNow.ToUnixTimeSeconds().ToString();
        var path = $"/api/v1/io/file/{fileId}";
        var signature = CalculateSignature("GET", path, timestamp);

        // GET 请求：使用请求头传递身份信息
        var request = new HttpRequestMessage(HttpMethod.Get, path);
        request.Headers.Add("X-Api-Key", _config.ApiKey);
        request.Headers.Add("X-Project-Code", _config.ProjectCode);
        request.Headers.Add("X-Timestamp", timestamp);
        request.Headers.Add("X-Signature", signature);
        request.Headers.Add("X-External-UserId", externalUserId); // 必填：用户身份

        var response = await _httpClient.SendAsync(request, HttpCompletionOption.ResponseHeadersRead);
        response.EnsureSuccessStatusCode();

        return await response.Content.ReadAsStreamAsync();
    }

    /// <summary>生成安全的文件访问令牌（用于前端直接预览/下载）</summary>
    public async Task<FileAccessTokenResponse> GenerateFileAccessTokenAsync(Int64 fileId, String externalUserId, Int32 expiresInMinutes = 30)
    {
        var timestamp = DateTimeOffset.UtcNow.ToUnixTimeSeconds().ToString();
        var path = $"/api/v1/io/file/{fileId}/access-token";
        var signature = CalculateSignature("GET", path, timestamp);

        // 使用 Query 参数传递过期时间
        var requestUri = $"{path}?expiresInMinutes={expiresInMinutes}";

        var request = new HttpRequestMessage(HttpMethod.Get, requestUri);
        request.Headers.Add("X-Api-Key", _config.ApiKey);
        request.Headers.Add("X-Project-Code", _config.ProjectCode);
        request.Headers.Add("X-Timestamp", timestamp);
        request.Headers.Add("X-Signature", signature);
        request.Headers.Add("X-External-UserId", externalUserId);

        var response = await _httpClient.SendAsync(request);
        response.EnsureSuccessStatusCode();

        var json = await response.Content.ReadAsStringAsync();
        var result = JsonSerializer.Deserialize<DGResult<FileAccessTokenResponse>>(json, new JsonSerializerOptions
        {
            PropertyNameCaseInsensitive = true
        });

        if (result?.Code != 200)
            throw new Exception($"生成访问令牌失败：{result?.Message} (ErrCode: {result?.ErrCode})");

        return result.Data;
    }

    /// <summary>删除文件</summary>
    public async Task<Boolean> DeleteFileAsync(Int64 fileId, String reason, String externalUserId)
    {
        var timestamp = DateTimeOffset.UtcNow.ToUnixTimeSeconds().ToString();
        var signature = CalculateSignature("DELETE", $"/api/v1/io/{fileId}", timestamp);

        var formData = new MultipartFormDataContent
        {
            { new StringContent(reason), "remark" }
        };

        var request = new HttpRequestMessage(HttpMethod.Delete, $"/api/v1/io/{fileId}")
        {
            Content = formData
        };
        request.Headers.Add("X-External-UserId", externalUserId); // 必填请求头
        request.Headers.Add("X-Api-Key", _config.ApiKey);
        request.Headers.Add("X-Project-Code", _config.ProjectCode);
        request.Headers.Add("X-Timestamp", timestamp);
        request.Headers.Add("X-Signature", signature);

        var response = await _httpClient.SendAsync(request);
        return response.IsSuccessStatusCode;
    }

    /// <summary>计算 API 签名</summary>
    private String CalculateSignature(String method, String path, String timestamp)
    {
        // 签名字符串：METHOD:PATH:TIMESTAMP:APIKEY
        var signString = $"{method.ToUpper()}:{path}:{timestamp}:{_config.ApiKey}";

        using var hmac = new HMACSHA256(Encoding.UTF8.GetBytes(_config.ApiSecret));
        var hashBytes = hmac.ComputeHash(Encoding.UTF8.GetBytes(signString));
        return BitConverter.ToString(hashBytes).Replace("-", "").ToLower();
    }
}

{
    /// <summary>状态码（200=成功）</summary>
    public Int32 Code { get; set; }

    /// <summary>错误代码（成功时为0）</summary>
    public Int32 ErrCode { get; set; }

    /// <summary>消息</summary>
    public String Message { get; set; }

    /// <summary>数据</summary>
    public T Data { get; set; }
}
```

```csharp
public class FileService : IFileService

    private readonly IEasyIOClient _easyIOClient;
    // 假设有业务数据库服务
    // private readonly IRepository<BusinessFile> _repository;

    {

    /// <summary>获取上传令牌</summary>
    public async Task<UploadTokenDto> GetUploadTokenAsync(GetUploadTokenRequest request, String userId)
    {
        // 参数验证
```

```typescript
// src/utils/fileUploader.ts
import SparkMD5 from 'spark-md5';
import axios, { AxiosProgressEvent } from 'axios';

/** 上传令牌响应 */
export interface UploadTokenResponse {
  uploadToken: string;          // 注意：字段名是 uploadToken 不是 token
  chunkUploadUrl: string;
  mergeUrl: string;
  statusUrl: string;
  expiresAt: string;
  fileHash: string;
  maxChunkSize: number;
  message?: string;
}

/** 上传进度回调 */
export interface UploadProgress {
  percent: number;
  loaded: number;
  total: number;
  stage: 'calculating' | 'uploading' | 'merging';
}

/** 分片上传器 */
export class ChunkedFileUploader {
  private file: File;
  private token: string;
  private config: UploadTokenResponse['config'];
  private fileHash: string = '';
  private chunks: Blob[] = [];
  private uploadedChunks: Set<number> = new Set();
  private onProgress?: (progress: UploadProgress) => void;
  private abortController?: AbortController;

  constructor(
    file: File,
    tokenResponse: UploadTokenResponse,
    onProgress?: (progress: UploadProgress) => void
  ) {
    this.file = file;
    this.token = tokenResponse.uploadToken;  // 使用 uploadToken 字段
    this.config = {
      chunkSize: tokenResponse.maxChunkSize || 5 * 1024 * 1024,
      chunkUploadUrl: tokenResponse.chunkUploadUrl,
      mergeUrl: tokenResponse.mergeUrl,
      statusUrl: tokenResponse.statusUrl
    };
    this.onProgress = onProgress;
  }

  /** 计算文件 MD5 */
  private async calculateMD5(): Promise<string> {
    return new Promise((resolve, reject) => {
      const spark = new SparkMD5.ArrayBuffer();
      const fileReader = new FileReader();
      const chunkSize = 2 * 1024 * 1024; // 2MB per chunk for MD5
      let currentChunk = 0;
      const chunks = Math.ceil(this.file.size / chunkSize);

      fileReader.onload = (e) => {
        spark.append(e.target!.result as ArrayBuffer);
        currentChunk++;

        if (this.onProgress) {
          this.onProgress({
            percent: Math.floor((currentChunk / chunks) * 100),
            loaded: currentChunk * chunkSize,
            total: this.file.size,
            stage: 'calculating'
          });
        }

        if (currentChunk < chunks) {
          loadNext();
        } else {
          const hash = spark.end().toLowerCase();
          resolve(hash);
        }
      };

      fileReader.onerror = reject;

      const loadNext = () => {
        const start = currentChunk * chunkSize;
        const end = Math.min(start + chunkSize, this.file.size);
        fileReader.readAsArrayBuffer(this.file.slice(start, end));
      };

      loadNext();
    });
  }

  /** 切分文件 */
  private splitFile(): void {
    const chunkSize = this.config.chunkSize;
    const chunks: Blob[] = [];
    let start = 0;

    while (start < this.file.size) {
      const end = Math.min(start + chunkSize, this.file.size);
      chunks.push(this.file.slice(start, end));
      start = end;
    }

    this.chunks = chunks;
  }

  /** 查询已上传的分片 */
  private async queryUploadedChunks(): Promise<number[]> {
    try {
      const response = await axios.get(
        this.config.statusUrl.replace('{fileHash}', this.fileHash),
        {
          headers: {
            'X-Upload-Token': this.token
          }
        }
      );

      if (response.data.code === 200 && response.data.data.exists) {
        return response.data.data.uploadedChunks || [];
      }
    } catch (error) {
      console.warn('查询分片状态失败，将重新上传:', error);
    }
    return [];
  }

  /** 上传单个分片 */
  private async uploadChunk(index: number): Promise<void> {
    const formData = new FormData();
    formData.append('file', this.chunks[index], `chunk_${index}`);
    formData.append('chunkIndex', index.toString());
    formData.append('totalChunks', this.chunks.length.toString());
    formData.append('fileHash', this.fileHash);
    formData.append('fileName', this.file.name);
    formData.append('fileSize', this.file.size.toString());

    this.abortController = new AbortController();

    await axios.post(this.config.chunkUploadUrl, formData, {
      headers: {
        'X-Upload-Token': this.token
      },
      signal: this.abortController.signal,
      onUploadProgress: (e: AxiosProgressEvent) => {
        if (this.onProgress && e.total) {
          const uploadedSize = Array.from(this.uploadedChunks).reduce(
            (sum, i) => sum + this.chunks[i].size,
            0
          );
          const currentChunkProgress = e.loaded;

          this.onProgress({
            percent: Math.floor(
              ((uploadedSize + currentChunkProgress) / this.file.size) * 100
            ),
            loaded: uploadedSize + currentChunkProgress,
            total: this.file.size,
            stage: 'uploading'
          });
        }
      }
    });

    this.uploadedChunks.add(index);
  }

  /** 并发上传分片 */
  private async uploadChunksConcurrently(
    chunkIndices: number[],
    concurrency: number = 3
  ): Promise<void> {
    const queue = [...chunkIndices];
    const workers: Promise<void>[] = [];

    const worker = async () => {
      while (queue.length > 0) {
        const index = queue.shift()!;
        await this.uploadChunk(index);
      }
    };

    for (let i = 0; i < Math.min(concurrency, chunkIndices.length); i++) {
      workers.push(worker());
    }

    await Promise.all(workers);
  }

  /** 合并分片 */
  private async mergeChunks(): Promise<any> {
    const formData = new FormData();
    formData.append('fileHash', this.fileHash);
    formData.append('fileName', this.file.name);
    formData.append('totalChunks', this.chunks.length.toString());
    formData.append('remark', `上传文件: ${this.file.name}`);

    const response = await axios.post(this.config.mergeUrl, formData, {
      headers: {
        'X-Upload-Token': this.token
      }
    });

    if (response.data.code !== 200) {
      throw new Error(response.data.message || '合并失败');
    }

    return response.data.data;
  }

  /** 执行上传 */
  public async upload(): Promise<any> {
    try {
      // 1. 计算文件 MD5
      this.fileHash = await this.calculateMD5();

      // 2. 切分文件
      this.splitFile();

      // 3. 查询已上传的分片（断点续传）
      const uploadedChunks = await this.queryUploadedChunks();
      this.uploadedChunks = new Set(uploadedChunks);

      // 4. 上传未完成的分片
      const pendingChunks = Array.from(
        { length: this.chunks.length },
        (_, i) => i
      ).filter((i) => !this.uploadedChunks.has(i));

      if (pendingChunks.length > 0) {
        await this.uploadChunksConcurrently(pendingChunks, 3);
      }

      // 5. 合并分片
      if (this.onProgress) {
        this.onProgress({
          percent: 99,
          loaded: this.file.size,
          total: this.file.size,
          stage: 'merging'
        });
      }

      const result = await this.mergeChunks();

      if (this.onProgress) {
        this.onProgress({
          percent: 100,
          loaded: this.file.size,
          total: this.file.size,
          stage: 'merging'
        });
      }

      return result;
    } catch (error: any) {
      if (axios.isCancel(error)) {
        throw new Error('上传已取消');
      }
      throw error;
    }
  }

  /** 取消上传 */
  public abort(): void {
    if (this.abortController) {
      this.abortController.abort();
    }
  }
}

/** 文件上传服务 */
export class FileUploadService {
  private baseURL: string;

  constructor(baseURL: string = '/api/file') {
    this.baseURL = baseURL;
  }

  /** 获取上传令牌 */
  public async getUploadToken(
    file: File,
    businessType: string,
    businessId?: string
  ): Promise<UploadTokenResponse> {
    // 先计算文件 MD5
    const fileHash = await this.calculateFileMD5(file);

    const response = await axios.post(`${this.baseURL}/upload-token`, {
      fileHash,
      fileName: file.name,
      fileSize: file.size,
      businessType,
      businessId
    });

    if (response.data.code !== 200) {
      throw new Error(response.data.message || '获取令牌失败');
    }

    return response.data.data;
  }

  /** 确认上传 */
  public async confirmUpload(
    fileId: number,
    businessType: string,
    businessId?: string
  ): Promise<void> {
    const response = await axios.post(`${this.baseURL}/confirm`, {
      fileId,
      businessType,
      businessId
    });

    if (response.data.code !== 200) {
      throw new Error(response.data.message || '确认上传失败');
    }
  }

  /** 计算文件 MD5 */
  private async calculateFileMD5(file: File): Promise<string> {
    return new Promise((resolve, reject) => {
      const spark = new SparkMD5.ArrayBuffer();
      const fileReader = new FileReader();
      const chunkSize = 2 * 1024 * 1024;
      let currentChunk = 0;
      const chunks = Math.ceil(file.size / chunkSize);

      fileReader.onload = (e) => {
        spark.append(e.target!.result as ArrayBuffer);
        currentChunk++;

        if (currentChunk < chunks) {
          loadNext();
        } else {
          resolve(spark.end().toLowerCase());
        }
      };

      fileReader.onerror = reject;

      const loadNext = () => {
        const start = currentChunk * chunkSize;
        const end = Math.min(start + chunkSize, file.size);
        fileReader.readAsArrayBuffer(file.slice(start, end));
      };

      loadNext();
    });
  }

  /** 上传文件（完整流程）*/
  public async uploadFile(
    file: File,
    businessType: string,
    businessId: string,
    onProgress?: (progress: UploadProgress) => void
  ): Promise<number> {
    // 1. 获取令牌
    const tokenResponse = await this.getUploadToken(
      file,
      businessType,
      businessId
    );

    // 2. 执行上传
    const uploader = new ChunkedFileUploader(file, tokenResponse, onProgress);
    const uploadResult = await uploader.upload();

    // 3. 确认上传
    await this.confirmUpload(uploadResult.id, businessType, businessId);

    return uploadResult.id;
  }
```

```vue
  if (bytes < 1024 * 1024 * 1024) return (bytes / 1024 / 1024).toFixed(2) + ' MB';
  return (bytes / 1024 / 1024 / 1024).toFixed(2) + ' GB';
};
```

```vue
async function downloadViaProxy(fileId: number) {
  try {
    loading.value = true;
    loadingText.value = '正在下载文件...';

    // GET 请求，后端验证权限后返回文件流

  } catch (error: any) {
    if (error.response?.status === 403) {
      alert('无权访问该文件');
    } else if (error.response?.status === 401) {
      alert('请先登录');
    } else {
      alert('下载失败: ' + (error.response?.data?.message || error.message));

    loading.value = false;
```

## 3. 内部项目文件安全访问总结

### 3.1 三种访问方式对比

| 方式 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **后端代理下载** | • 最安全，业务后端完全可控<br>• 可记录下载日志<br>• 无令牌泄露风险 | • 占用业务服务器带宽<br>• 文件流经业务服务器 | • 高安全要求<br>• 需要审计日志<br>• 文件较小（<100MB） |
| **令牌直接访问** | • 减轻业务服务器压力<br>• 前端直接访问 EasyIO<br>• 适合预览场景 | • 令牌可能被截获<br>• 需要设置短过期时间 | • 在线预览<br>• 临时分享<br>• 图片/PDF 查看 |
| **后端代理预览** | • 安全性较高<br>• 支持 inline 模式<br>• 浏览器内预览 | • 占用带宽<br>• 不适合大文件 | • 在线预览<br>• PDF/图片查看<br>• 嵌入页面展示 |

### 3.2 安全要点

#### 后端安全（必须实现）
1. **身份验证**：所有请求验证用户身份（JWT/Session）
2. **权限检查**：验证用户是否有权访问指定文件
3. **AccessLevel 验证**：确认文件确实是内部项目文件（AccessLevel=3）
4. **请求签名**：使用 HMAC-SHA256 签名防止请求伪造
5. **日志审计**：记录所有文件访问操作（用户、时间、文件ID、IP）

#### 前端安全（建议实施）
1. **令牌存储**：访问令牌仅保存在内存，不存localStorage
2. **超时处理**：令牌过期后重新获取，不缓存过期令牌
3. **错误处理**：403/401 错误引导用户重新登录
4. **URL 清理**：预览完成后清理 Blob URL（`URL.revokeObjectURL`）

#### EasyIO 层安全（平台提供）
1. **令牌时效**：访问令牌默认 30 分钟过期
2. **一次性令牌**：可选配置令牌仅使用一次
3. **IP 绑定**：可选绑定令牌与客户端 IP
4. **请求频率限制**：防止令牌滥用

```csharp
{
    // 1. 查询文件关联的业务实体
    var fileRecord = await _dbContext.BusinessFiles
        .FirstOrDefaultAsync(f => f.FileId == fileId);
    
    if (fileRecord == null)
        return false;

    // 2. 根据业务类型检查权限
    return fileRecord.BusinessType switch
    {
        "order-attachment" => await CheckOrderPermissionAsync(fileRecord.BusinessId, userId),
        "project-document" => await CheckProjectPermissionAsync(fileRecord.BusinessId, userId),
        "contract-file" => await CheckContractPermissionAsync(fileRecord.BusinessId, userId),
        _ => false
    };
}

        return false;

    // 仅订单创建人、负责人、管理员可访问
```

## 5. 关键要点

### 5.1 安全性

#### 上传安全
1. **令牌绑定文件哈希**：令牌只能上传指定的文件，防止滥用
2. **令牌有效期**：默认2小时，过期后需重新申请
3. **API 签名验证**：业务后端调用 EasyIO 使用 HMAC-SHA256 签名
4. **前端不暴露密钥**：前端只使用令牌，不接触 API Key/Secret

#### 内部文件访问安全（AccessLevel=3）
1. **三层验证**：
   - 业务后端：验证用户身份和业务权限
   - EasyIO：验证 API 签名和项目权限
   - 关联验证：确认文件与业务实体的归属关系

2. **推荐方式**：
   - **生产环境**：优先使用后端代理下载，完全可控
   - **预览场景**：可使用短期访问令牌（<30分钟）
   - **审计要求**：必须记录所有访问日志（用户、文件、时间、IP、操作）

3. **禁止做法**：
   - ❌ 前端直接调用 EasyIO API（会暴露 API Key）
   - ❌ 将文件 URL 存储到前端 localStorage
   - ❌ 长期有效的访问令牌（>1小时）
   - ❌ 跨用户共享访问令牌

### 5.2 性能优化

1. **并发上传**：3个分片同时上传，充分利用带宽
2. **断点续传**：上传前查询状态，跳过已上传分片
3. **前端直传**：文件不经过业务服务器，减少中转开销
4. **流式处理**：分片上传和 MD5 计算都使用流式处理，不占用大内存

### 5.3 用户体验

1. **实时进度**：显示百分比、速度、剩余时间
2. **可取消**：支持中途取消上传
3. **拖拽上传**：支持拖放文件到上传区域
4. **错误提示**：清晰的错误信息和重试机制

### D. 签名计算（API Key 模式）

```csharp
// 签名字符串格式：METHOD:PATH:TIMESTAMP:APIKEY
string signString = $"POST:/api/v1/io/upload-token:1705392000:your-api-key";

// 使用 HMAC-SHA256 计算签名
using var hmac = new HMACSHA256(Encoding.UTF8.GetBytes(apiSecret));
byte[] hashBytes = hmac.ComputeHash(Encoding.UTF8.GetBytes(signString));
string signature = BitConverter.ToString(hashBytes).Replace("-", "").ToLower();
```

## 7. 访问级别（AccessLevel）说明

| 级别 | 名称 | 说明 | 访问方式 | 适用场景 |
|------|------|------|----------|----------|
| 0 | 默认 | 遵循项目默认设置 | 根据项目配置 | 普通业务文件 |
| 1 | 公开 | 任何人可访问（无需鉴权） | 直接 URL 访问 | 公开资源、营销素材 |
| 2 | 私有 | 需要项目鉴权（API Key） | 带签名的 URL | 企业内部文件 |
| 3 | **内部项目** | 需要用户级鉴权 | **后端代理 或 访问令牌** | **敏感文档、合同、个人信息** |

```csharp
    return File(fileStream, "application/octet-stream", "contract.pdf");
}
```
