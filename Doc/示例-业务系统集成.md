# 业务系统集成示例

本文档展示如何在业务系统中集成 EasyIO 文件上传/下载服务，包括完整的前后端代码示例，特别是**如何在业务层实现用户级权限控制**。

> **⚠️ 重要提示：实际项目关键差异**
> 
> ### 通用规则
> 1. **POST/DELETE 请求使用 Form 参数**（`multipart/form-data`），不是 JSON Body
> 2. **GET 请求使用 Query 参数或请求头**，不能使用表单
> 3. **必填请求头**：`X-External-UserId`（外部用户ID，用于身份验证）
> 4. **响应结构**：使用 `DGResult<T>` 包装，包含 `Code`、`ErrCode`、`Message`、`Data`
> 5. **令牌字段名**：返回的是 `uploadToken`（不是 `token`）
> 6. **API 基础路径**：`/api/v1/io/...`（注意版本号）
> 
> ### 用户级权限控制（业务层实现）
> 7. **EasyIO 限制**：存储层仅支持项目级权限（AccessLevel=1/2/3），不支持用户级细粒度权限
> 8. **业务层方案**：在业务数据库记录文件与用户的关联关系，业务后端验证权限
> 9. **访问方式**：必须通过业务后端代理访问，不得暴露 EasyIO 直接访问地址
> 10. **审计日志**：在业务层记录所有文件访问操作（用户、时间、操作类型）

## 核心优势

1. **前端直传**：文件不经过业务服务器，减少带宽和CPU消耗（适用于公开/私有文件）
2. **安全可控**：令牌绑定文件哈希，防止滥用；私有文件（用户级）强制权限验证
3. **断点续传**：支持大文件分片上传，网络中断可恢复
4. **统一管理**：所有文件集中存储，便于审计和管理
5. **灵活访问控制**：支持 4 级访问权限（默认/公开/私有-项目级/私有-用户级）

```csharp
/// <summary>EasyIO 客户端实现</summary>
public class EasyIOClient : IEasyIOClient
{
    private readonly HttpClient _httpClient;
    private readonly EasyIOConfig _config;

    public EasyIOClient(HttpClient httpClient, IOptions<EasyIOConfig> config)
    {
        _httpClient = httpClient;
        _config = config.Value;
        _httpClient.BaseAddress = new Uri(_config.BaseUrl);
    }

    /// <summary>生成上传令牌</summary>
    /// <param name="externalUserId">外部用户ID（必填）</param>
    public async Task<UploadTokenResponse> GenerateUploadTokenAsync(GenerateTokenRequest request, String externalUserId)
    {
        // 构造表单数据
        var formData = new MultipartFormDataContent
        {
            { new StringContent(request.FileHash), "fileHash" },
            { new StringContent(request.FileName), "fileName" },
            { new StringContent(request.FileSize.ToString()), "fileSize" }
        };

        if (!String.IsNullOrEmpty(request.Category))
            formData.Add(new StringContent(request.Category), "category");
        if (!String.IsNullOrEmpty(request.BusinessType))
            formData.Add(new StringContent(request.BusinessType), "businessType");
        if (!String.IsNullOrEmpty(request.BusinessId))
            formData.Add(new StringContent(request.BusinessId), "businessId");
        if (request.AccessLevel > 0)
            formData.Add(new StringContent(request.AccessLevel.ToString()), "accessLevel");
        if (!String.IsNullOrEmpty(request.Directory))
            formData.Add(new StringContent(request.Directory), "directory");
        if (request.ExpiresInMinutes != 60)
            formData.Add(new StringContent(request.ExpiresInMinutes.ToString()), "expiresInMinutes");

        // 添加签名头
        var timestamp = DateTimeOffset.UtcNow.ToUnixTimeSeconds().ToString();
        var signature = CalculateSignature("POST", "/api/v1/io/upload-token", timestamp);

        var httpRequest = new HttpRequestMessage(HttpMethod.Post, "/api/v1/io/upload-token")
        {
            Content = formData
        };
        httpRequest.Headers.Add("X-Api-Key", _config.ApiKey);
        httpRequest.Headers.Add("X-Project-Code", _config.ProjectCode);
        httpRequest.Headers.Add("X-Timestamp", timestamp);
        httpRequest.Headers.Add("X-Signature", signature);
        httpRequest.Headers.Add("X-External-UserId", externalUserId); // 必填请求头

        var response = await _httpClient.SendAsync(httpRequest);
        response.EnsureSuccessStatusCode();

        var json = await response.Content.ReadAsStringAsync();
        var result = JsonSerializer.Deserialize<DGResult<UploadTokenResponse>>(json, new JsonSerializerOptions
        {
            PropertyNameCaseInsensitive = true
        });

        if (result?.Code != 200)
            throw new Exception($"生成令牌失败：{result?.Message} (ErrCode: {result?.ErrCode})");

        return result.Data;
    }

    /// <summary>查询文件信息</summary>
    public async Task<FileInfoResponse> GetFileInfoAsync(Int64 fileId)
    {
        var timestamp = DateTimeOffset.UtcNow.ToUnixTimeSeconds().ToString();
        var signature = CalculateSignature("GET", $"/api/v1/io/info/{fileId}", timestamp);

        var request = new HttpRequestMessage(HttpMethod.Get, $"/api/v1/io/info/{fileId}");
        request.Headers.Add("X-Api-Key", _config.ApiKey);
        request.Headers.Add("X-Project-Code", _config.ProjectCode);
        request.Headers.Add("X-Timestamp", timestamp);
        request.Headers.Add("X-Signature", signature);

        var response = await _httpClient.SendAsync(request);
        response.EnsureSuccessStatusCode();

        var json = await response.Content.ReadAsStringAsync();
        var result = JsonSerializer.Deserialize<ApiResult<FileInfoResponse>>(json, new JsonSerializerOptions
        {
            PropertyNameCaseInsensitive = true
        });

        return result?.Data;
    }

    /// <summary>批量生成签名URL（调用EasyIO的实际API）</summary>
    public async Task<List<SignedUrlResult>> GenerateSignedUrlsAsync(List<Int64> fileIds, Int32 expiresInSeconds = 3600)
    {
        var timestamp = DateTimeOffset.UtcNow.ToUnixTimeSeconds().ToString();
        var path = "/api/v1/io/signed-urls";
        var signature = CalculateSignature("POST", path, timestamp);

        var requestBody = new
        {
            fileIds = fileIds,
            expiresInSeconds = expiresInSeconds,
            baseUrl = _config.BaseUrl.Replace("/api/v1/io", "")
        };

        var request = new HttpRequestMessage(HttpMethod.Post, path);
        request.Content = new StringContent(
            JsonSerializer.Serialize(requestBody),
            Encoding.UTF8,
            "application/json"
        );
        
        request.Headers.Add("X-Api-Key", _config.ApiKey);
        request.Headers.Add("X-Project-Code", _config.ProjectCode);
        request.Headers.Add("X-Timestamp", timestamp);
        request.Headers.Add("X-Signature", signature);

        var response = await _httpClient.SendAsync(request);
        response.EnsureSuccessStatusCode();

        var json = await response.Content.ReadAsStringAsync();
        var result = JsonSerializer.Deserialize<SignedUrlsResponse>(json, new JsonSerializerOptions
        {
            PropertyNameCaseInsensitive = true
        });

        return result?.Urls ?? new List<SignedUrlResult>();
    }

    /// <summary>删除文件</summary>
    public async Task<Boolean> DeleteFileAsync(Int64 fileId, String reason, String externalUserId)
    {
        var timestamp = DateTimeOffset.UtcNow.ToUnixTimeSeconds().ToString();
        var signature = CalculateSignature("DELETE", $"/api/v1/io/{fileId}", timestamp);

        var formData = new MultipartFormDataContent
        {
            { new StringContent(reason), "remark" }
        };

        var request = new HttpRequestMessage(HttpMethod.Delete, $"/api/v1/io/{fileId}")
        {
            Content = formData
        };
        request.Headers.Add("X-External-UserId", externalUserId); // 必填请求头
        request.Headers.Add("X-Api-Key", _config.ApiKey);
        request.Headers.Add("X-Project-Code", _config.ProjectCode);
        request.Headers.Add("X-Timestamp", timestamp);
        request.Headers.Add("X-Signature", signature);

        var response = await _httpClient.SendAsync(request);
        return response.IsSuccessStatusCode;
    }

    /// <summary>计算 API 签名</summary>
    private String CalculateSignature(String method, String path, String timestamp)
    {
        // 签名字符串：METHOD:PATH:TIMESTAMP:APIKEY
        var signString = $"{method.ToUpper()}:{path}:{timestamp}:{_config.ApiKey}";

        using var hmac = new HMACSHA256(Encoding.UTF8.GetBytes(_config.ApiSecret));
        var hashBytes = hmac.ComputeHash(Encoding.UTF8.GetBytes(signString));
        return BitConverter.ToString(hashBytes).Replace("-", "").ToLower();
    }
}

/// <summary>DG 统一响应结果</summary>
public class DGResult<T>
{
    /// <summary>状态码（200=成功）</summary>
    public Int32 Code { get; set; }

    /// <summary>错误代码（成功时为0）</summary>
    public Int32 ErrCode { get; set; }

    /// <summary>消息</summary>
    public String Message { get; set; }

    /// <summary>数据</summary>
    public T Data { get; set; }
}
```

```typescript
// src/utils/fileUploader.ts
import SparkMD5 from 'spark-md5';
import axios, { AxiosProgressEvent } from 'axios';

/** 上传令牌响应 */
export interface UploadTokenResponse {
  uploadToken: string;          // 注意：字段名是 uploadToken 不是 token
  chunkUploadUrl: string;
  mergeUrl: string;
  statusUrl: string;
  expiresAt: string;
  fileHash: string;
  maxChunkSize: number;
  message?: string;
}

/** 上传进度回调 */
export interface UploadProgress {
  percent: number;
  loaded: number;
  total: number;
  stage: 'calculating' | 'uploading' | 'merging';
}

/** 分片上传器 */
export class ChunkedFileUploader {
  private file: File;
  private token: string;
  private config: UploadTokenResponse['config'];
  private fileHash: string = '';
  private chunks: Blob[] = [];
  private uploadedChunks: Set<number> = new Set();
  private onProgress?: (progress: UploadProgress) => void;
  private abortController?: AbortController;

  constructor(
    file: File,
    tokenResponse: UploadTokenResponse,
    onProgress?: (progress: UploadProgress) => void
  ) {
    this.file = file;
    this.token = tokenResponse.uploadToken;  // 使用 uploadToken 字段
    this.config = {
      chunkSize: tokenResponse.maxChunkSize || 5 * 1024 * 1024,
      chunkUploadUrl: tokenResponse.chunkUploadUrl,
      mergeUrl: tokenResponse.mergeUrl,
      statusUrl: tokenResponse.statusUrl
    };
    this.onProgress = onProgress;
  }

  /** 计算文件 MD5 */
  private async calculateMD5(): Promise<string> {
    return new Promise((resolve, reject) => {
      const spark = new SparkMD5.ArrayBuffer();
      const fileReader = new FileReader();
      const chunkSize = 2 * 1024 * 1024; // 2MB per chunk for MD5
      let currentChunk = 0;
      const chunks = Math.ceil(this.file.size / chunkSize);

      fileReader.onload = (e) => {
        spark.append(e.target!.result as ArrayBuffer);
        currentChunk++;

        if (this.onProgress) {
          this.onProgress({
            percent: Math.floor((currentChunk / chunks) * 100),
            loaded: currentChunk * chunkSize,
            total: this.file.size,
            stage: 'calculating'
          });
        }

        if (currentChunk < chunks) {
          loadNext();
        } else {
          const hash = spark.end().toLowerCase();
          resolve(hash);
        }
      };

      fileReader.onerror = reject;

      const loadNext = () => {
        const start = currentChunk * chunkSize;
        const end = Math.min(start + chunkSize, this.file.size);
        fileReader.readAsArrayBuffer(this.file.slice(start, end));
      };

      loadNext();
    });
  }

  /** 切分文件 */
  private splitFile(): void {
    const chunkSize = this.config.chunkSize;
    const chunks: Blob[] = [];
    let start = 0;

    while (start < this.file.size) {
      const end = Math.min(start + chunkSize, this.file.size);
      chunks.push(this.file.slice(start, end));
      start = end;
    }

    this.chunks = chunks;
  }

  /** 查询已上传的分片 */
  private async queryUploadedChunks(): Promise<number[]> {
    try {
      const response = await axios.get(
        this.config.statusUrl.replace('{fileHash}', this.fileHash),
        {
          headers: {
            'X-Upload-Token': this.token
          }
        }
      );

      if (response.data.code === 200 && response.data.data.exists) {
        return response.data.data.uploadedChunks || [];
      }
    } catch (error) {
      console.warn('查询分片状态失败，将重新上传:', error);
    }
    return [];
  }

  /** 上传单个分片 */
  private async uploadChunk(index: number): Promise<void> {
    const formData = new FormData();
    formData.append('file', this.chunks[index], `chunk_${index}`);
    formData.append('chunkIndex', index.toString());
    formData.append('totalChunks', this.chunks.length.toString());
    formData.append('fileHash', this.fileHash);
    formData.append('fileName', this.file.name);
    formData.append('fileSize', this.file.size.toString());

    this.abortController = new AbortController();

    await axios.post(this.config.chunkUploadUrl, formData, {
      headers: {
        'X-Upload-Token': this.token
      },
      signal: this.abortController.signal,
      onUploadProgress: (e: AxiosProgressEvent) => {
        if (this.onProgress && e.total) {
          const uploadedSize = Array.from(this.uploadedChunks).reduce(
            (sum, i) => sum + this.chunks[i].size,
            0
          );
          const currentChunkProgress = e.loaded;

          this.onProgress({
            percent: Math.floor(
              ((uploadedSize + currentChunkProgress) / this.file.size) * 100
            ),
            loaded: uploadedSize + currentChunkProgress,
            total: this.file.size,
            stage: 'uploading'
          });
        }
      }
    });

    this.uploadedChunks.add(index);
  }

  /** 并发上传分片 */
  private async uploadChunksConcurrently(
    chunkIndices: number[],
    concurrency: number = 3
  ): Promise<void> {
    const queue = [...chunkIndices];
    const workers: Promise<void>[] = [];

    const worker = async () => {
      while (queue.length > 0) {
        const index = queue.shift()!;
        await this.uploadChunk(index);
      }
    };

    for (let i = 0; i < Math.min(concurrency, chunkIndices.length); i++) {
      workers.push(worker());
    }

    await Promise.all(workers);
  }

  /** 合并分片 */
  private async mergeChunks(): Promise<any> {
    const formData = new FormData();
    formData.append('fileHash', this.fileHash);
    formData.append('fileName', this.file.name);
    formData.append('totalChunks', this.chunks.length.toString());
    formData.append('remark', `上传文件: ${this.file.name}`);

    const response = await axios.post(this.config.mergeUrl, formData, {
      headers: {
        'X-Upload-Token': this.token
      }
    });

    if (response.data.code !== 200) {
      throw new Error(response.data.message || '合并失败');
    }

    return response.data.data;
  }

  /** 执行上传 */
  public async upload(): Promise<any> {
    try {
      // 1. 计算文件 MD5
      this.fileHash = await this.calculateMD5();

      // 2. 切分文件
      this.splitFile();

      // 3. 查询已上传的分片（断点续传）
      const uploadedChunks = await this.queryUploadedChunks();
      this.uploadedChunks = new Set(uploadedChunks);

      // 4. 上传未完成的分片
      const pendingChunks = Array.from(
        { length: this.chunks.length },
        (_, i) => i
      ).filter((i) => !this.uploadedChunks.has(i));

      if (pendingChunks.length > 0) {
        await this.uploadChunksConcurrently(pendingChunks, 3);
      }

      // 5. 合并分片
      if (this.onProgress) {
        this.onProgress({
          percent: 99,
          loaded: this.file.size,
          total: this.file.size,
          stage: 'merging'
        });
      }

      const result = await this.mergeChunks();

      if (this.onProgress) {
        this.onProgress({
          percent: 100,
          loaded: this.file.size,
          total: this.file.size,
          stage: 'merging'
        });
      }

      return result;
    } catch (error: any) {
      if (axios.isCancel(error)) {
        throw new Error('上传已取消');
      }
      throw error;
    }
  }

  /** 取消上传 */
  public abort(): void {
    if (this.abortController) {
      this.abortController.abort();
    }
  }
}

/** 文件上传服务 */
export class FileUploadService {
  private baseURL: string;

  constructor(baseURL: string = '/api/file') {
    this.baseURL = baseURL;
  }

  /** 获取上传令牌 */
  public async getUploadToken(
    file: File,
    businessType: string,
    businessId?: string
  ): Promise<UploadTokenResponse> {
    // 先计算文件 MD5
    const fileHash = await this.calculateFileMD5(file);

    const response = await axios.post(`${this.baseURL}/upload-token`, {
      fileHash,
      fileName: file.name,
      fileSize: file.size,
      businessType,
      businessId
    });

    if (response.data.code !== 200) {
      throw new Error(response.data.message || '获取令牌失败');
    }

    return response.data.data;
  }

  /** 确认上传 */
  public async confirmUpload(
    fileId: number,
    businessType: string,
    businessId?: string
  ): Promise<void> {
    const response = await axios.post(`${this.baseURL}/confirm`, {
      fileId,
      businessType,
      businessId
    });

    if (response.data.code !== 200) {
      throw new Error(response.data.message || '确认上传失败');
    }
  }

  /** 计算文件 MD5 */
  private async calculateFileMD5(file: File): Promise<string> {
    return new Promise((resolve, reject) => {
      const spark = new SparkMD5.ArrayBuffer();
      const fileReader = new FileReader();
      const chunkSize = 2 * 1024 * 1024;
      let currentChunk = 0;
      const chunks = Math.ceil(file.size / chunkSize);

      fileReader.onload = (e) => {
        spark.append(e.target!.result as ArrayBuffer);
        currentChunk++;

        if (currentChunk < chunks) {
          loadNext();
        } else {
          resolve(spark.end().toLowerCase());
        }
      };

      fileReader.onerror = reject;

      const loadNext = () => {
        const start = currentChunk * chunkSize;
        const end = Math.min(start + chunkSize, file.size);
        fileReader.readAsArrayBuffer(file.slice(start, end));
      };

      loadNext();
    });
  }

  /** 上传文件（完整流程）*/
  public async uploadFile(
    file: File,
    businessType: string,
    businessId: string,
    onProgress?: (progress: UploadProgress) => void
  ): Promise<number> {
    // 1. 获取令牌
    const tokenResponse = await this.getUploadToken(
      file,
      businessType,
      businessId
    );

    // 2. 执行上传
    const uploader = new ChunkedFileUploader(file, tokenResponse, onProgress);
    const uploadResult = await uploader.upload();

    // 3. 确认上传
    await this.confirmUpload(uploadResult.id, businessType, businessId);

    return uploadResult.id;
  }
}
```

## 3. 私有文件（用户级）安全访问总结

### 3.1 主流对象存储的私有资源访问方案（七牛云、阿里云 OSS、腾讯云 COS）

#### 业界标准做法：临时签名 URL（Signed URL）

主流对象存储服务（如七牛云、阿里云 OSS、AWS S3）处理私有图片/文件时，都采用**临时签名 URL** 方案：

```
典型的签名 URL 结构：
https://cdn.example.com/image.jpg?e=1706774400&token=abc123...

参数说明：
- e (expires): 过期时间戳（Unix timestamp）
- token: HMAC 签名，由 SecretKey + 资源路径 + 过期时间 计算得出
```

**核心原理**：
1. 后端根据用户权限，使用 **SecretKey** 生成带签名的临时 URL
2. URL 包含**过期时间**（通常 5 分钟 ~ 24 小时）
3. 前端直接用这个 URL 加载图片（img src / background-image）
4. CDN/存储服务验证签名和时效，通过则返回资源

**优势**：
- ✅ **前端无感知**：`<img src="签名URL">` 直接使用，无需特殊处理
- ✅ **高性能**：图片直接从 CDN 加载，不经过业务服务器
- ✅ **安全可控**：签名 URL 有时效，无法被长期滥用
- ✅ **支持缓存**：浏览器可正常缓存图片（在有效期内）

#### 七牛云实际示例

```csharp
// C# 后端生成七牛云私有空间的下载链接
public String GenerateQiniuPrivateUrl(String fileKey, Int32 expiresInSeconds = 3600)
{
    var baseUrl = $"https://cdn.example.com/{fileKey}";
    var deadline = DateTimeOffset.UtcNow.ToUnixTimeSeconds() + expiresInSeconds;
    
    // 构造待签名字符串
    var signString = $"{baseUrl}?e={deadline}";
    
    // HMAC-SHA1 签名
    using var hmac = new HMACSHA1(Encoding.UTF8.GetBytes(_qiniuSecretKey));
    var signBytes = hmac.ComputeHash(Encoding.UTF8.GetBytes(signString));
    var token = Convert.ToBase64String(signBytes)
        .Replace('+', '-').Replace('/', '_'); // URL 安全的 Base64
    
    return $"{signString}&token={_qiniuAccessKey}:{token}";
}
```

```csharp
{
```
```csharp
    var userId = User.Identity?.Name;
```

- ❌ 无法利用浏览器缓存
- ❌ 不适合大图片

### 3.3 三种访问方式对比

| 方式 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **临时签名 URL**<br>（推荐） | • 前端无感知，直接 `<img src>`<br>• 高性能，CDN 加速<br>• 支持浏览器缓存<br>• 不占用服务器带宽 | • 需要实现签名算法<br>• URL 可能被短期共享 | • 图片展示（列表/详情）<br>• PDF 预览<br>• 视频播放<br>• 高频访问资源 |
| **后端代理下载** | • 最安全，完全可控<br>• 可记录下载日志<br>• 无令牌泄露风险 | • 占用业务服务器带宽<br>• 文件流经业务服务器<br>• 不支持浏览器缓存 | • 高安全要求<br>• 需要审计日志<br>• 文件下载（非预览）<br>• 一次性访问 |
| **Base64 Data URL** | • 无需额外请求<br>• 适合极小文件 | • 数据量增加 33%<br>• 无法缓存<br>• 内存占用高 | • 小图标（<10KB）<br>• 初次加载可见内容<br>• 邮件嵌入图片 |

### 3.4 安全要点

#### 后端安全（必须实现）
1. **身份验证**：所有请求验证用户身份（JWT/Session）
2. **权限检查**：验证用户是否有权访问指定文件
3. **AccessLevel 验证**：确认文件的访问级别符合业务要求（AccessLevel=2或3都支持签名URL）
4. **请求签名**：使用 HMAC-SHA256 签名防止请求伪造
5. **日志审计**：记录所有文件访问操作（用户、时间、文件ID、IP）

#### 前端安全（建议实施）
1. **URL存储**：签名URL仅保存在内存，不存localStorage
2. **超时处理**：签名URL过期后重新生成，不缓存过期URL
3. **错误处理**：403/401 错误引导用户重新登录
4. **URL 清理**：预览完成后清理 Blob URL（`URL.revokeObjectURL`）

#### EasyIO 层安全（平台提供）
1. **签名时效**：签名URL默认1小时过期，最长7天
2. **签名验证**：使用HMAC-SHA256验证签名的有效性
3. **项目隔离**：签名URL仅对指定项目有效
4. **请求频率限制**：防止签名URL滥用

## 5. 关键要点

### 5.1 安全性

#### 上传安全
1. **令牌绑定文件哈希**：令牌只能上传指定的文件，防止滥用
2. **令牌有效期**：默认2小时，过期后需重新申请
3. **API 签名验证**：业务后端调用 EasyIO 使用 HMAC-SHA256 签名
4. **前端不暴露密钥**：前端只使用令牌，不接触 API Key/Secret

#### 私有文件访问安全（用户级，AccessLevel=3）
1. **三层验证**：
   - 业务后端：验证用户身份和业务权限（用户级）
   - EasyIO：验证 API 签名和项目权限
   - 关联验证：确认文件与业务实体的归属关系和用户访问权

2. **推荐方式**：
   - **生产环境**：优先使用后端代理下载，完全可控
   - **预览场景**：可使用短期签名URL（<30分钟）
   - **审计要求**：必须记录所有访问日志（用户、文件、时间、IP、操作）

3. **禁止做法**：
   - ❌ 前端直接调用 EasyIO API（会暴露 API Key）
   - ❌ 将文件 URL 存储到前端 localStorage
   - ❌ 长期有效的签名URL（>1小时）
   - ❌ 跨用户共享签名URL

### 5.2 性能优化

1. **并发上传**：3个分片同时上传，充分利用带宽
2. **断点续传**：上传前查询状态，跳过已上传分片
3. **前端直传**：文件不经过业务服务器，减少中转开销
4. **流式处理**：分片上传和 MD5 计算都使用流式处理，不占用大内存

### 5.3 用户体验

1. **实时进度**：显示百分比、速度、剩余时间
2. **可取消**：支持中途取消上传
3. **拖拽上传**：支持拖放文件到上传区域
4. **错误提示**：清晰的错误信息和重试机制

## 7. 访问级别（AccessLevel）说明

| 级别 | 名称 | 当前实现 | 访问方式 | 适用场景 |
|------|------|---------|----------|----------|
| 0 | 默认 | 遵循项目默认设置 | 根据项目配置 | 普通业务文件 |
| 1 | 公开 | 任何人可访问（无需鉴权） | 直接 URL 访问 | 公开资源、营销素材 |
| 2 | 私有 | 需要项目鉴权（API Key或签名URL） | 带签名的 URL | 项目内部文件 |
| 3 | **内部** | 与AccessLevel=2行为相同，项目级权限 | 带签名的 URL | 预留扩展字段，当前与私有(2)一致 |

> **💡 当前实现说明**：
> - **AccessLevel=2（私有）**：需要项目API Key验证或使用签名URL访问
> - **AccessLevel=3（内部）**：**当前版本与AccessLevel=2行为完全相同**，都是项目级权限控制
> 
> **⚠️ 重要限制**：当前 EasyIO 系统**不支持用户级权限验证**。
> 
> 如果需要实现"**用户A只能访问自己的文件**"这种场景，必须在**业务层面**进行权限控制。

### 业务层实现用户级权限控制（推荐方案）

```csharp
// ⚠️ 注意：EasyIO 存储层不会验证用户权限
// 业务层必须自己实现权限控制

// 1. 上传时在业务数据库记录文件归属
public async Task<Int64> UploadUserFileAsync(IFormFile file, String userId)
{
    // 上传到 EasyIO（使用 AccessLevel=2 即可，权限由业务层控制）
    var fileId = await _easyIOClient.UploadFileAsync(file, accessLevel: 2);
    
    // 在业务数据库记录文件与用户的关联
    await _dbContext.UserFiles.AddAsync(new UserFile
    {
        FileId = fileId,
        UserId = userId,  // 文件归属用户
        FileName = file.FileName,
        UploadTime = DateTime.Now
    });
    await _dbContext.SaveChangesAsync();
    
    return fileId;
}

// 2. 下载时验证用户权限（业务层控制）
public async Task<IActionResult> DownloadUserFile(Int64 fileId, String currentUserId)
{
    // 从业务数据库查询文件归属
    var userFile = await _dbContext.UserFiles.FirstOrDefaultAsync(f => f.FileId == fileId);
    if (userFile == null)
        return NotFound("文件不存在");
    
    // 业务层权限验证：只有文件所有者可以下载
    if (userFile.UserId != currentUserId)
        return Forbid("您无权访问该文件");
    
    // 权限验证通过，从 EasyIO 获取文件流
    var fileStream = await _easyIOClient.GetFileStreamAsync(fileId);
    return File(fileStream, "application/octet-stream", userFile.FileName);
}

// 3. 更复杂的权限场景：基于角色和关联关系
public async Task<Boolean> CheckFileAccessPermissionAsync(Int64 fileId, String userId)
{
    var userFile = await _dbContext.UserFiles
        .Include(f => f.SharedUsers)  // 包含共享用户
        .FirstOrDefaultAsync(f => f.FileId == fileId);
    
    if (userFile == null) return false;
    
    // 文件所有者可以访问
    if (userFile.UserId == userId) return true;
    
    // 管理员可以访问
    if (await _userManager.IsInRoleAsync(userId, "Admin")) return true;
    
    // 文件已共享给当前用户
    if (userFile.SharedUsers.Any(s => s.UserId == userId)) return true;
    
    // 业务关联关系（如：订单的买家和卖家都可以访问订单附件）
    if (!String.IsNullOrEmpty(userFile.BusinessType) && !String.IsNullOrEmpty(userFile.BusinessId))
    {
        return await CheckBusinessRelationAsync(userFile.BusinessType, userFile.BusinessId, userId);
    }
    
    return false;
}
```

|------------|--------------|-----------|---------|
| 1 (公开) | ❌ 无需验证 | ❌ 无需验证 | 公开资源，直接访问 |
| 2 (私有) | ✅ 验证 API Key（项目级） | 看业务需求 | 项目内部文件 |
| 3 (内部) | ✅ 更高权限要求 | 看业务需求 | 系统内部文件 |
| **用户级权限** | ❌ **EasyIO 不提供** | ✅ **必须业务层实现** | 个人文件、敏感信息 |

> **🎯 推荐实践**：
> 1. **不需要用户级权限**：使用 AccessLevel=1 或 2，简单快捷
> 2. **需要用户级权限**：
>    - 使用 AccessLevel=2（私有）
>    - 在业务数据库记录文件与用户的关联关系
>    - 在业务后端实现权限验证逻辑
>    - 通过业务后端代理访问文件（不暴露 EasyIO 的直接访问地址）

### 9.2 签名 URL 的生成算法

#### 七牛云示例

```csharp
// 七牛云私有空间下载签名
public String GenerateQiniuPrivateUrl(String fileKey, Int32 expiresInSeconds = 3600)
{
    var baseUrl = $"http://your-bucket.qiniucdn.com/{fileKey}";
    var deadline = DateTimeOffset.UtcNow.ToUnixTimeSeconds() + expiresInSeconds;
    
    // 签名字符串
    var signString = $"{baseUrl}?e={deadline}";
    
    // HMAC-SHA1 签名
    using var hmac = new HMACSHA1(Encoding.UTF8.GetBytes(_secretKey));
    var signBytes = hmac.ComputeHash(Encoding.UTF8.GetBytes(signString));
    var encodedSign = ToUrlSafeBase64(signBytes);
    
    // 最终URL
    return $"{signString}&token={_accessKey}:{encodedSign}";
}
```

```csharp
/// <summary>业务服务层：为前端生成签名URL（带缓存优化）</summary>
public class FileService : IFileService
{
    private readonly IMemoryCache _cache;
    private readonly IEasyIOClient _easyIOClient;

    /// <summary>获取文件的签名URL（用于前端直接渲染）</summary>
    public async Task<SignedUrlResult> GetFileSignedUrlAsync(Int64 fileId, String userId)
    {
        // 1. 验证用户权限
        var hasPermission = await CheckUserFilePermissionAsync(fileId, userId);
        if (!hasPermission)
            throw new UnauthorizedAccessException("无权访问该文件");

        // 2. 尝试从缓存获取（可选优化，缓存时长比签名有效期短）
        var cacheKey = $"signed_url:{fileId}:{userId}";
        if (_cache.TryGetValue<SignedUrlResult>(cacheKey, out var cachedResult))
        {
            // 如果缓存的URL还有5分钟以上有效期，直接返回
            if (cachedResult.ExpiresAt.Subtract(DateTime.UtcNow).TotalMinutes > 5)
            {
                return cachedResult;
            }
        }

        // 3. 生成新的签名URL（30分钟有效）
        var result = await _easyIOClient.GenerateSignedUrlsAsync(
            new[] { fileId },
            expiresIn: 1800 // 30分钟（秒）
        );
        
        var signedUrl = result.Urls[0];

        // 4. 缓存签名URL（缓存时长为有效期的80%，即24分钟）
        _cache.Set(cacheKey, signedUrl, TimeSpan.FromMinutes(24));

        // 5. 记录访问日志（可选）
        await LogFileAccessAsync(fileId, userId, "generate_signed_url");

        return signedUrl;
    }
}
```

### 9.6 签名 URL 的安全加固

```csharp
/// <summary>签名URL生成（增强安全性）</summary>
public class SignedUrlGenerator
{
    /// <summary>生成签名URL（包含IP绑定、防盗链等）</summary>
    public String GenerateSecureSignedUrl(
        Int64 fileId,
        String userId,
        String clientIp,
        Int32 expiresInMinutes = 30)
    {
        var baseUrl = $"{_config.CdnBaseUrl}/file/{fileId}";
        var expires = DateTimeOffset.UtcNow.AddMinutes(expiresInMinutes).ToUnixTimeSeconds();
        
        // 签名内容：文件ID + 用户ID + IP + 过期时间 + 密钥
        var signString = $"{fileId}:{userId}:{clientIp}:{expires}";
        
        using var hmac = new HMACSHA256(Encoding.UTF8.GetBytes(_config.ApiSecret));
        var signBytes = hmac.ComputeHash(Encoding.UTF8.GetBytes(signString));
        var signature = Convert.ToBase64String(signBytes)
            .Replace("+", "-")
            .Replace("/", "_")
            .TrimEnd('=');
        
        // URL格式: /file/{id}?expires={ts}&uid={uid}&ip={ip}&sign={sign}
        return $"{baseUrl}?expires={expires}&uid={userId}&ip={clientIp}&sign={signature}";
    }
}

/// <summary>EasyIO 服务端：验证签名URL（中间件）</summary>
public class SignedUrlValidationMiddleware
{
    public async Task InvokeAsync(HttpContext context)
    {
        if (context.Request.Path.StartsWithSegments("/file"))
        {
            // 1. 提取参数
            var expires = long.Parse(context.Request.Query["expires"]);
            var userId = context.Request.Query["uid"];
            var clientIp = context.Request.Query["ip"];
            var signature = context.Request.Query["sign"];
            
            // 2. 验证过期时间
            if (DateTimeOffset.UtcNow.ToUnixTimeSeconds() > expires)
            {
                context.Response.StatusCode = 403;
                await context.Response.WriteAsync("URL已过期");
                return;
            }
            
            // 3. 验证IP（可选，严格模式）
            var actualIp = context.Connection.RemoteIpAddress?.ToString();
            if (clientIp != actualIp)
            {
                context.Response.StatusCode = 403;
                await context.Response.WriteAsync("IP不匹配");
                return;
            }
            
            // 4. 验证签名
            var fileId = ExtractFileIdFromPath(context.Request.Path);
            var expectedSign = CalculateSignature(fileId, userId, clientIp, expires);
            if (signature != expectedSign)
            {
                context.Response.StatusCode = 403;
                await context.Response.WriteAsync("签名无效");
                return;
            }
            
            // 5. 签名验证通过，继续处理
            await _next(context);
        }
        else
        {
            await _next(context);
        }
    }
}
```

### 9.7 总结：何时使用签名 URL

#### ✅ 适合使用签名 URL 的场景
- 图片展示（相册、商品图、用户头像）
- 视频播放（教学视频、监控回放）
- PDF 在线预览
- 高频访问的静态资源
- CDN 加速需求

#### ❌ 不适合使用签名 URL 的场景
- 高度敏感文档（合同原件、财务报表）
- 需要详细审计日志的下载
- 一次性下载（下载即删除）
- 需要实时权限校验（权限可能随时变更）

#### 🎯 推荐实践
1. **图片/视频预览**：使用签名 URL
2. **文件下载**：使用后端代理
3. **混合方案**：根据文件类型和场景智能选择
4. **安全加固**：签名 URL 绑定用户ID和IP，设置短过期时间（5-30分钟）

### 9.8 签名 URL 的缓存策略与生命周期管理

#### 问题分析

你提出的三个关键问题：

1. **前端怎么知道签名快过期？**
   - ✅ 后端返回 `expiresAt` 和 `suggestedRefreshAt` 时间
   - ✅ 前端根据 `suggestedRefreshAt` 设置定时器自动刷新
   - ✅ 客户端时间校准（通过 `serverTime` 计算时间差）

2. **是不是每次都要请求业务系统？**
   - ❌ 不是每次都请求
   - ✅ 首次加载请求一次
   - ✅ 达到 `suggestedRefreshAt` 时间后自动刷新（通常是过期前5分钟）
   - ✅ 图片加载失败时主动刷新

3. **签名由业务系统缓存还是怎样？**
   - ✅ 业务后端建议缓存（Redis/内存缓存）
   - ✅ 缓存时长为签名有效期的 80%（24分钟，签名30分钟）
   - ✅ 缓存 Key：`signed_url:{fileId}:{userId}`

#### 完整的生命周期时序图

#### 缓存策略详解

##### 后端缓存（推荐）

```csharp
/// <summary>签名URL缓存策略</summary>
public class SignedUrlCacheStrategy
{
    private readonly IDistributedCache _cache; // Redis 或 内存缓存

    /// <summary>获取或生成签名URL（带缓存）</summary>
    public async Task<SignedUrlResult> GetOrCreateSignedUrlAsync(
        Int64 fileId, 
        String userId,
        Func<Task<SignedUrlResult>> generator)
    {
        var cacheKey = $"signed_url:{fileId}:{userId}";

        // 1. 尝试从缓存获取
        var cachedJson = await _cache.GetStringAsync(cacheKey);
        if (!String.IsNullOrEmpty(cachedJson))
        {
            var cached = JsonSerializer.Deserialize<SignedUrlResult>(cachedJson);
            
            // 检查是否还有足够的剩余时间（至少5分钟）
            if (cached.ExpiresAt.Subtract(DateTime.UtcNow).TotalMinutes > 5)
            {
                Console.WriteLine($"[Cache] 命中缓存: fileId={fileId}, userId={userId}");
                return cached;
            }
        }

        // 2. 缓存未命中或即将过期，生成新的签名URL
        var newResult = await generator();

        // 3. 缓存新的签名URL（缓存时长为有效期的80%）
        var expiresIn = (newResult.ExpiresAt - DateTime.UtcNow).TotalSeconds;
        var cacheExpiration = TimeSpan.FromSeconds(expiresIn * 0.8);
        await _cache.SetStringAsync(
            cacheKey, 
            JsonSerializer.Serialize(newResult),
            new DistributedCacheEntryOptions
            {
                AbsoluteExpirationRelativeToNow = cacheExpiration
            });

        Console.WriteLine($"[Cache] 已缓存: fileId={fileId}, userId={userId}, expires={cacheExpiration}");
        return newResult;
    }
}
```

```typescript
// 前端全局签名URL管理器（Vuex/Pinia）
import { defineStore } from 'pinia';

interface SignedUrlCache {
  signedUrl: string;
  expiresAt: Date;
  suggestedRefreshAt: Date;
}

export const useSignedUrlStore = defineStore('signedUrl', {
  state: () => ({
    cache: new Map<number, SignedUrlCache>()
  }),

  actions: {
    /** 获取签名URL（优先从缓存） */
    async getSignedUrl(fileId: number): Promise<string> {
      const cached = this.cache.get(fileId);
      
      // 检查缓存是否有效（距离过期时间还有5分钟以上）
      if (cached) {
        const now = new Date();
        const remainingMinutes = (cached.expiresAt.getTime() - now.getTime()) / 1000 / 60;
        
        if (remainingMinutes > 5) {
          console.log(`[Store] 使用缓存的签名URL: fileId=${fileId}`);
          return cached.signedUrl;
        }
      }

      // 缓存失效，重新请求
      console.log(`[Store] 重新请求签名URL: fileId=${fileId}`);
      const response = await axios.get(`/api/file/internal/${fileId}/signed-url`);
      
      this.cache.set(fileId, {
        signedUrl: response.data.signedUrl,
        expiresAt: new Date(response.data.expiresAt),
        suggestedRefreshAt: new Date(response.data.suggestedRefreshAt)
      });

      return response.data.signedUrl;
    },

    /** 清除指定文件的缓存 */
    clearCache(fileId: number) {
      this.cache.delete(fileId);
    },

    /** 清除所有缓存 */
    clearAllCache() {
      this.cache.clear();
    }
  }
});
```

#### 性能优化建议

| 场景 | 缓存位置 | 缓存时长 | 说明 |
|------|---------|---------|------|
| **单用户单文件** | 业务后端 + 前端内存 | 24分钟 | 最常见场景，缓存命中率高 |
| **多用户同一文件** | 业务后端（按用户ID） | 24分钟 | 每个用户独立签名，保证安全 |
| **图片列表页** | 前端 Vuex/Pinia | 24分钟 | 避免重复请求相同文件 |
| **长时间停留页面** | 前端自动刷新 | - | 定时器确保签名不过期 |

#### 流量分析（以100张图片为例）

**无缓存方案**：
- 页面停留 60 分钟
- 签名有效期 30 分钟
- 刷新次数：60 / 30 = 2 次
- 总请求：100 张图片 × 2 次 = **200 次请求**

**有后端缓存方案**：
- 首次加载：100 次请求（生成签名）
- 25 分钟刷新：100 次请求（大部分命中缓存，实际调用 EasyIO：0 次）
- 总请求：**200 次业务后端请求，但仅 100 次 EasyIO 请求**

**有前端+后端缓存方案**：
- 首次加载：100 次请求
- 用户在页面内切换/滚动：0 次请求（前端缓存）
- 25 分钟刷新：100 次后端请求（命中缓存，返回极快）
- 总请求：**200 次业务后端请求（极快），100 次 EasyIO 请求**

#### 最佳实践总结

1. **后端必须缓存**：减少对 EasyIO 的调用，降低延迟
2. **前端可选缓存**：适用于图片列表、相册等场景
3. **自动刷新机制**：前端根据 `suggestedRefreshAt` 自动刷新，用户无感知
4. **时间校准**：后端返回 `serverTime`，前端计算时间差，确保定时器准确
5. **缓存时长**：后端缓存 80% 有效期，前端刷新在 83%（25/30）时触发
6. **容错机制**：图片加载失败时立即刷新签名URL

```csharp
/// <summary>签名URL性能监控</summary>
public class SignedUrlMetrics
{
    public Int64 TotalRequests { get; set; }        // 总请求数
    public Int64 CacheHits { get; set; }            // 缓存命中数
    public Int64 CacheMisses { get; set; }          // 缓存未命中数

    public Int64 EasyIOCalls { get; set; }          // 实际调用 EasyIO 次数
    public Double AverageResponseTime { get; set; } // 平均响应时间(ms)
}
```
